# Rolling Sky: TIFCO (The Infinity Innovation Engine Co-Creation Contest) - IIE Level Collections (.ilp)
Hello! This is a Github Repository that has all of the IIE level collections containing TIFCO levels from their respective rounds.

Note that all levels are sorted from release order by the main level, meaning the bonus level will be right below the main.
If the bonus is harder than the main, then it will be placed first.
^^ This is a decision made by the TIFCO Team as the release orders for Round 4 were simply stupid.

To download and import the collections, simply:
1. On the Repository's main page, go to the right corner of the file listing and click Code > Download .zip.
2. Extract all collections using a .zip extractor tool.
3. Open IIE (preferably use the latest Android version), go to your collections and import a collection. (cloud download icon).
4. A menu should appear. On the left hand side, click "Browse...".
5. Locate the folder the collection is in and click "Use this folder".
